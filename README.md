# Primary teacher job finder

A simple web page listing primary/junior class teacher vacancies near a chosen postcode (default HX4 8LG, 10 miles), full-time jobs first, nearest first.

- `index.html` – the page. It reloads `jobs.json` every time it is opened.
- `jobs.json` – the job list, refreshed each morning by a scheduled Claude task.

Live site: https://iand74.github.io/teacher-job-finder/
